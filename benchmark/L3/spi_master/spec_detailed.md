## 功能
单从机 SPI 主机，模式 0（CPOL = 0，CPHA = 0）：sclk 空闲为低，从机在 sclk **上升沿**采样 mosi，主机在 sclk **上升沿**采样 miso，数据在 sclk 下降沿（及片选拉低时）更新，MSB 先发。每次传输 8 位，全双工。

## 参数
| 参数 | 默认值 | 说明 |
|---|---|---|
| CLK_DIV | 4 | sclk 半周期长度（单位：clk 周期），取值 ≥ 1 |

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | input | 1 | 系统时钟 |
| rst_n | input | 1 | **同步**复位，低电平有效 |
| start | input | 1 | 启动传输，仅在 busy = 0 时被接受，持续为高则连续传输 |
| tx_data | input | 8 | 待发送数据，在 start 被接受的上升沿采样 |
| rx_data | output | 8 | 接收到的数据，在 done 为 1 的周期有效并保持到下一次传输结束 |
| busy | output | 1 | 传输进行中 |
| done | output | 1 | 传输完成脉冲，持续 1 个周期 |
| sclk | output | 1 | 串行时钟，空闲为 0 |
| mosi | output | 1 | 主机输出数据 |
| miso | input | 1 | 从机输入数据 |
| cs_n | output | 1 | 片选，低有效，空闲为 1 |

## 行为（均以 clk 上升沿为准）
1. 复位：`busy = 0`，`done = 0`，`sclk = 0`，`cs_n = 1`。
2. 接受 start：`busy = 0` 且 `start = 1` 的上升沿接受一次传输，采样 tx_data；之后的周期 `busy = 1`、`cs_n = 0`，mosi 输出 tx_data[7]。传输期间的 start 被忽略。
3. sclk：cs_n 拉低后经过 CLK_DIV（允许 CLK_DIV + 1）个周期出现第一个上升沿；此后每 CLK_DIV 个周期翻转一次，即周期为 2·CLK_DIV，一次传输恰好 8 个上升沿；cs_n = 1 时 sclk 必须为 0。
4. 数据：主机在每个 sclk 上升沿采样 miso（第 k 个上升沿得到 rx_data[7−k]，k = 0…7）；在每个 sclk 下降沿把 mosi 切换为下一位。
5. 结束：第 8 个下降沿之后 sclk 保持 0，cs_n 回到 1，`done` 输出 1 个周期的脉冲，rx_data 更新为本次接收的字节；done 为 1 的下一个周期 `busy = 0`、`cs_n = 1`。从 start 被接受到 done 不超过 16·CLK_DIV + 8 个周期。
6. 传输过程中复位：立即回到复位状态（cs_n = 1，sclk = 0，busy = 0），不产生 done。

## 时序示例（CLK_DIV = 1，即 sclk 每个周期翻转，tx_data = 8'hA5）
| 周期 | 0 | 1 | 2 | 3 | 4 | 5 | … | 16 | 17 | 18 |
|---|---|---|---|---|---|---|---|---|---|---|
| start | 1 | 0 | 0 | 0 | 0 | 0 | … | 0 | 0 | 0 |
| busy | 0 | 1 | 1 | 1 | 1 | 1 | … | 1 | 0 | 0 |
| cs_n | 1 | 0 | 0 | 0 | 0 | 0 | … | 0 | 1 | 1 |
| sclk | 0 | 0 | 1 | 0 | 1 | 0 | … | 0 | 0 | 0 |
| mosi | – | 1 | 1 | 0 | 0 | 1 | … | 1 | – | – |
| done | 0 | 0 | 0 | 0 | 0 | 0 | … | 0 | 1 | 0 |

周期 1 为 start 被接受后的第一个周期；第 8 个下降沿出现在周期 16 之后，周期 17 输出 done。
