## 功能
全双工 UART 收发器，帧格式 **8N1**（1 位起始位、8 位数据、无校验、1 位停止位），数据低位先发。波特率由参数 `CLKS_PER_BIT` 决定：每一位持续 `CLKS_PER_BIT` 个 `clk` 周期。

## 参数
| 参数 | 默认值 | 说明 |
|---|---|---|
| CLKS_PER_BIT | 16 | 每位所占的时钟周期数（≥ 8，偶数） |

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | input | 1 | 时钟 |
| rst_n | input | 1 | **同步**复位，低电平有效 |
| tx_start | input | 1 | 发送请求，高电平一个周期即可 |
| tx_data | input | 8 | 待发送字节，在 `tx_start = 1` 且 `tx_busy = 0` 的上升沿被锁存 |
| tx_busy | output | 1 | 发送忙：从帧开始到停止位结束为 1 |
| tx | output | 1 | 串行输出，空闲为高 |
| rx | input | 1 | 串行输入，空闲为高（已与 `clk` 同步，无需亚稳态处理） |
| rx_data | output | 8 | 接收到的字节，在 `rx_valid = 1` 时有效并保持到下一帧 |
| rx_valid | output | 1 | 接收完成脉冲，宽度 1 个周期 |
| rx_err | output | 1 | 帧错误脉冲（停止位不为 1），宽度 1 个周期 |

## 发送行为
1. 复位后 `tx = 1`，`tx_busy = 0`。
2. `tx_start = 1` 且 `tx_busy = 0` 的上升沿：锁存 `tx_data`，`tx_busy` 变为 1，并开始输出起始位（`tx = 0`）。
3. 依次输出起始位、`tx_data[0]`～`tx_data[7]`、停止位（`tx = 1`），每位恰好持续 `CLKS_PER_BIT` 个周期，整帧共 10 × `CLKS_PER_BIT` 个周期。
4. 停止位结束后 `tx_busy` 回到 0，`tx` 保持 1。`tx_busy = 1` 期间的 `tx_start` 被忽略。
5. 允许的时序偏差：从 `tx_busy` 变 1 到起始位开始不超过 1 个周期；每位宽度偏差不超过 ±1 个周期；整帧长度（起始位下降沿到 `tx_busy` 下降）为 10 × `CLKS_PER_BIT` ± 2 个周期。

## 接收行为
1. 空闲时等待 `rx` 从 1 变 0（起始位）。
2. 检测到下降沿后，在 `CLKS_PER_BIT/2` 个周期后（起始位中点）再次采样 `rx`：若不为 0 视为毛刺，返回空闲，不产生任何输出。
3. 之后每隔 `CLKS_PER_BIT` 个周期在位中点采样一次，依次得到 `rx_data[0]`～`rx_data[7]` 与停止位。
4. 停止位采样为 1：输出 `rx_data`，并使 `rx_valid` 为 1 一个周期；停止位采样为 0：`rx_err` 为 1 一个周期，`rx_valid` 保持 0，`rx_data` 不作要求。
5. 停止位采样后立即回到空闲，以便接收无间隔的连续帧。
6. 允许的时序偏差：`rx_valid` / `rx_err` 脉冲出现在停止位中点采样后的 0～`CLKS_PER_BIT/2` 个周期内；输入帧的位宽允许有 ±1 个周期的抖动，只要从起始位下降沿到停止位中点的累计偏差不超过 ±(`CLKS_PER_BIT/2` − 2) 个周期，就必须被正确接收。
