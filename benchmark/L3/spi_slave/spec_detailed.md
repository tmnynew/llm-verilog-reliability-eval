## 功能
运行在系统时钟 clk 下的 SPI 从机，模式 0（CPOL = 0，CPHA = 0），MSB 先发。sclk 频率不超过 clk 的 1/16（sclk 每个半周期至少 8 个 clk 周期），三个 SPI 输入均为异步信号，须经 clk 同步后再检测边沿。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | input | 1 | 系统时钟 |
| rst_n | input | 1 | **同步**复位，低电平有效 |
| sclk | input | 1 | 来自主机的串行时钟，空闲为 0 |
| cs_n | input | 1 | 片选，低有效 |
| mosi | input | 1 | 主机输出数据，在 sclk 上升沿采样 |
| miso | output | 1 | 从机输出数据，cs_n = 1 时输出 0 |
| tx_data | input | 8 | 待发送数据，在 cs_n 下降沿装载；要求在 cs_n 拉低后至少保持 4 个 clk 周期稳定，之后的变化不影响本次传输 |
| rx_data | output | 8 | 收到的字节，rx_valid = 1 时有效并保持到下一次更新 |
| rx_valid | output | 1 | 每收到 8 位产生 1 个 clk 周期的脉冲 |

## 行为（均以 clk 上升沿为准）
1. 复位：`rx_valid = 0`，`miso = 0`，位计数清零。
2. 同步：sclk、cs_n、mosi 各经至少 2 级寄存器同步，边沿检测基于同步后的信号。文中的"下降沿/上升沿"均指同步后检测到的边沿，允许相对真实边沿有不超过 4 个 clk 周期的延迟。
3. 片选：检测到 cs_n 下降沿时装载 tx_data 到移位寄存器、位计数清零，并在 4 个 clk 周期内使 miso 输出 tx_data[7]。cs_n 为高时 miso 输出 0，且忽略 sclk。
4. 接收：cs_n 为低期间，每个 sclk 上升沿采样 mosi（MSB 先到）；第 8 个上升沿之后 4 个 clk 周期内，rx_data 更新为收到的字节，rx_valid 输出 1 个周期的脉冲；位计数清零，cs_n 继续为低时可接着接收下一个字节。
5. 发送：每个 sclk 下降沿之后 4 个 clk 周期内，miso 切换到下一位（tx_data[6]、tx_data[5]…）；8 位发完后 miso 输出 0。
6. cs_n 在 8 位未收满时拉高：丢弃已收到的位，不产生 rx_valid。

## 时序示例（每个 sclk 半周期 8 个 clk，只画关键事件）
| 事件 | cs_n ↓ | +3 clk | sclk ↑ ×1 | sclk ↓ ×1 | +3 clk | … | sclk ↑ ×8 | +3 clk |
|---|---|---|---|---|---|---|---|---|
| miso | 0 | tx[7] | tx[7] | tx[7] | tx[6] | … | tx[0] | 0 |
| 采样 mosi | – | – | rx[7] | – | – | … | rx[0] | – |
| rx_valid | 0 | 0 | 0 | 0 | 0 | … | 0 | 1（1 个周期） |
