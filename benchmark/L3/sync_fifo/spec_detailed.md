## 功能
单时钟同步 FIFO，先进先出，深度 `DEPTH`、数据宽度 `DW`。

## 参数
| 参数 | 默认值 | 说明 |
|---|---|---|
| DW | 8 | 数据位宽 |
| DEPTH | 16 | 存储深度（2 的幂） |

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | input | 1 | 时钟 |
| rst_n | input | 1 | **同步**复位，低电平有效 |
| wr_en | input | 1 | 写使能 |
| wr_data | input | DW | 写入数据 |
| rd_en | input | 1 | 读使能 |
| rd_data | output | DW | 读出数据（寄存器输出） |
| full | output | 1 | 满标志 |
| empty | output | 1 | 空标志 |
| count | output | log2(DEPTH)+1 | 当前存储的数据个数，0～DEPTH（默认 5 位） |

## 行为（均以时钟上升沿为准）
1. 复位：`rst_n = 0` 的上升沿清空 FIFO：`count = 0`，`empty = 1`，`full = 0`。`rd_data` 的复位值不作要求。
2. 写：在上升沿若 `wr_en = 1` 且 `full = 0`，`wr_data` 被写入队尾，称为"写被接受"。`full = 1` 时的写请求被忽略，已存数据不变。
3. 读：在上升沿若 `rd_en = 1` 且 `empty = 0`，队首数据出队，称为"读被接受"，并在**该上升沿之后**出现在 `rd_data` 上并保持到下一次读被接受为止。`empty = 1` 时的读请求被忽略，`rd_data` 保持不变。
4. 同一上升沿读写同时被接受时，`count` 不变，数据先出后入；满时同时读写：读被接受、写被忽略（因为该沿 `full = 1`）；空时同时读写：写被接受、读被忽略。
5. 标志：`empty = (count == 0)`，`full = (count == DEPTH)`，二者与 `count` 在同一周期内一致，可为组合或寄存输出，但必须在写/读被接受的上升沿之后的那个周期立即反映新状态（无额外延迟）。
6. 不得溢出或欠载：接受的写次数减去接受的读次数恒等于 `count`，且 0 ≤ `count` ≤ DEPTH。

## 时序示例（DEPTH = 4，每列为一个周期内的稳定值）
| 周期 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| rst_n | 0 | 1 | 1 | 1 | 1 | 1 | 1 | 1 | 1 |
| wr_en / wr_data | – | 1/A | 1/B | 1/C | 1/D | 1/E | 0 | 0 | 0 |
| rd_en | – | 0 | 0 | 0 | 0 | 1 | 1 | 1 | 1 |
| count | – | 0 | 1 | 2 | 3 | 4 | 3 | 2 | 1 |
| full | – | 0 | 0 | 0 | 0 | 1 | 0 | 0 | 0 |
| empty | – | 1 | 0 | 0 | 0 | 0 | 0 | 0 | 0 |
| rd_data | – | – | – | – | – | – | A | B | C |

第 6 周期 `full = 1`，写 E 被忽略、读 A 被接受；第 7 周期 `rd_data = A`。
