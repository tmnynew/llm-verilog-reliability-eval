## 功能
同步信号边沿检测器，可配置检测上升沿、下降沿或两者，并累计检测到的边沿个数。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | input | 1 | 时钟 |
| rst_n | input | 1 | **同步**复位，低电平有效 |
| sig | input | 1 | 被检测信号（已与 clk 同步） |
| mode | input | 2 | bit0 = 1 检测上升沿，bit1 = 1 检测下降沿；00 不检测，11 双边沿 |
| pulse | output | 1 | 检测到边沿时输出 1 个周期的高电平，寄存器输出 |
| cnt | output | 8 | 检测到的边沿总数，255 之后回到 0 |

## 行为（均以时钟上升沿为准）
1. 模块保存 `sig` 上一个上升沿的采样值 S。复位：`rst_n = 0` 的上升沿使 S = 0、`pulse = 0`、`cnt = 0`。
2. 每个上升沿采样 `sig`：若 sig = 1 且 S = 0 为上升沿；若 sig = 0 且 S = 1 为下降沿。随后 S 更新为本次采样值。
3. 若本次采样构成的边沿类型被当前 `mode` 选中，则该沿之后 `pulse = 1` 并持续 1 个周期，`cnt` 加 1；否则 `pulse = 0`，`cnt` 不变。
4. 因复位使 S = 0，复位释放后若 sig 已为 1，第一个上升沿即视为上升沿。
5. 允许的输出延迟窗口：`pulse` 与 `cnt` 的更新可比上述时刻**再晚 1 个周期**，脉冲个数与 cnt 的最终值必须一致。

## 时序示例（mode = 11）
| 上升沿序号 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| sig（该沿采样） | 0 | 1 | 1 | 0 | 0 | 1 |
| pulse（该沿之后） | 0 | 1 | 0 | 1 | 0 | 1 |
| cnt（该沿之后） | 0 | 1 | 1 | 2 | 2 | 3 |
