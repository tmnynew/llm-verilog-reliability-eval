## 功能
参数化模 N 加计数器，计数范围 0 ～ MOD−1。

## 参数
| 参数 | 默认值 | 说明 |
|---|---|---|
| WIDTH | 8 | `count` 的位宽，须满足 2^WIDTH ≥ MOD |
| MOD | 200 | 模值，计数到 MOD−1 后回到 0 |

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | input | 1 | 时钟，所有寄存器在上升沿动作 |
| rst_n | input | 1 | **同步**复位，低电平有效 |
| en | input | 1 | 计数使能 |
| count | output | WIDTH | 当前计数值（寄存器输出） |
| tc | output | 1 | 终值指示，组合输出 |

## 行为（均以时钟上升沿为准）
1. 复位：`rst_n = 0` 的上升沿，`count` 置 0。复位优先于 `en`。
2. 计数：`rst_n = 1` 且 `en = 1` 时，`count` 每个上升沿加 1；`count = MOD−1` 时下一值为 0。
3. 保持：`en = 0` 时 `count` 不变。
4. 终值指示：`tc = 1` 当且仅当 `count = MOD−1` 且 `en = 1`（与 `count`、`en` 同周期，无额外延迟）。
5. 允许的输出延迟窗口：0 个周期（`count` 必须在 `en` 有效的下一个上升沿后立即更新）。

## 时序示例（MOD = 4，每列为一个时钟周期内的稳定值）
| 周期 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| rst_n | 0 | 1 | 1 | 1 | 1 | 1 | 1 |
| en | x | 1 | 1 | 1 | 0 | 1 | 1 |
| count（本周期值） | x | 0 | 1 | 2 | 3 | 3 | 0 |
| tc | 0 | 0 | 0 | 0 | 0 | 1 | 0 |

第 1 周期末的上升沿执行复位，因此第 2 周期 `count = 0`；第 6 周期 `count = 3 = MOD−1` 且 `en = 1`，故 `tc = 1`，其后回到 0。
