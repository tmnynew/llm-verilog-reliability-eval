## 功能
8 位分辨率脉宽调制（PWM）发生器，周期固定为 256 个时钟周期，占空比设定值在周期边界锁存。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| clk | input | 1 | 时钟 |
| rst_n | input | 1 | **同步**复位，低电平有效 |
| duty | input | 8 | 占空比设定，0～255 |
| pwm | output | 1 | PWM 输出 |

## 行为（均以时钟上升沿为准）
1. 内部有一个 8 位自由运行计数器，复位值为 0，每个上升沿加 1，255 之后回到 0。
2. 内部有一个占空比锁存值 D：复位值为 0；仅在计数器由 255 回到 0 的那个上升沿，D 更新为当时的 `duty`；其余时刻 `duty` 的变化不影响 D。
3. `pwm` 在计数值 < D 的周期为 1，否则为 0。因此 D = 0 时 pwm 恒为 0，D = 255 时每周期有 255 个周期为 1、1 个周期为 0。
4. 复位期间 `pwm = 0`。
5. 允许的输出延迟窗口：`pwm` 可比上述时刻整体**再晚 1 个周期**，但每个 PWM 周期内高电平周期数和翻转次数必须一致。

## 时序示例（复位释放后 duty 恒为 3）
| 周期（复位释放后） | 1 | 2 | … | 256 | 257 | 258 | 259 | 260 | … |
|---|---|---|---|---|---|---|---|---|---|
| 计数值 | 0 | 1 | … | 255 | 0 | 1 | 2 | 3 | … |
| D | 0 | 0 | … | 0 | 3 | 3 | 3 | 3 | … |
| pwm | 0 | 0 | … | 0 | 1 | 1 | 1 | 0 | … |

第一个周期 D 仍为复位值 0，pwm 全 0；第 257 周期起 D = 3，每 256 个周期中前 3 个周期 pwm = 1。
