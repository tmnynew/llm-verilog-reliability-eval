## 功能
8 位组合逻辑优先编码器。对输入 `in[7:0]`，输出其中为 1 的**最高位**的位号。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| in | input | 8 | 待编码输入，`in[7]` 为最高优先级 |
| idx | output | 3 | 最高有效位的下标（0～7） |
| valid | output | 1 | `in` 中至少有一位为 1 时为 1，否则为 0 |

## 行为
1. 若 `in[k]=1` 且 `in[7:k+1]` 全为 0，则 `idx = k`，`valid = 1`。
2. 若 `in = 8'b0000_0000`，则 `valid = 0`，`idx = 3'b000`。
3. 纯组合逻辑，无时钟与复位。

## 示例
| in | idx | valid |
|---|---|---|
| 8'b1000_0000 | 7 | 1 |
| 8'b0010_1100 | 5 | 1 |
| 8'b0000_0001 | 0 | 1 |
| 8'b0000_0000 | 0 | 0 |
