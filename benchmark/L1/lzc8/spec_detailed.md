## 功能
统计 8 位输入从最高位（din[7]）开始连续为 0 的位数。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| din | input | 8 | 输入数据 |
| count | output | 4 | 前导零个数，取值 0～8 |
| zero | output | 1 | din 全为 0 时为 1 |

## 行为
1. `count` 等于满足 din[7] = din[6] = … = din[7−k+1] = 0 且 din[7−k] = 1 的 k；若 din 全 0，`count = 8`。
2. `zero = (din == 0)`。
3. 因 count 需要表示 8，输出位宽为 4 位。
4. 纯组合逻辑，无时钟与复位。

## 示例
| din | count | zero |
|---|---|---|
| 8'b1000_0000 | 0 | 0 |
| 8'b0000_0001 | 7 | 0 |
| 8'b0010_1100 | 2 | 0 |
| 8'b0000_0000 | 8 | 1 |
