## 功能
8 位组合逻辑桶形移位器，一个周期内完成任意 0～7 位的移位。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| din | input | 8 | 输入数据 |
| shamt | input | 3 | 移位量 0～7 |
| mode | input | 2 | 移位模式，见下表 |
| dout | output | 8 | 移位结果 |

## 模式
| mode | 操作 | 说明 |
|---|---|---|
| 2'b00 | 逻辑左移 | 低位补 0 |
| 2'b01 | 逻辑右移 | 高位补 0 |
| 2'b10 | 算术右移 | 高位补符号位 `din[7]` |
| 2'b11 | 循环左移 | 移出的高位回填到低位 |

## 行为
1. `shamt = 0` 时任何模式下 `dout = din`。
2. 纯组合逻辑，无时钟与复位。

## 示例
| din | shamt | mode | dout |
|---|---|---|---|
| 8'b1001_0110 | 2 | 00 | 8'b0101_1000 |
| 8'b1001_0110 | 2 | 01 | 8'b0010_0101 |
| 8'b1001_0110 | 2 | 10 | 8'b1110_0101 |
| 8'b1001_0110 | 2 | 11 | 8'b0101_1010 |
