## 功能
4 位二进制码 ↔ 反射格雷码双向转换器。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| din | input | 4 | 输入码 |
| mode | input | 1 | 0：二进制 → 格雷码；1：格雷码 → 二进制 |
| dout | output | 4 | 输出码 |

## 行为
1. 二进制 → 格雷码（mode = 0）：`dout[3] = din[3]`，`dout[i] = din[i+1] ^ din[i]`（i = 0,1,2）。
2. 格雷码 → 二进制（mode = 1）：`dout[3] = din[3]`，`dout[i] = dout[i+1] ^ din[i]`（i = 2,1,0），即二进制的每一位是格雷码从最高位到该位的异或累积。
3. 两种转换互为逆运算：对任意 x，先以 mode = 0 转换再以 mode = 1 转换应得到 x。
4. 纯组合逻辑，无时钟与复位。

## 示例
| din | mode | dout |
|---|---|---|
| 4'b0000 | 0 | 4'b0000 |
| 4'b0111 | 0 | 4'b0100 |
| 4'b1000 | 0 | 4'b1100 |
| 4'b1100 | 1 | 4'b1000 |
| 4'b0100 | 1 | 4'b0111 |
| 4'b1111 | 1 | 4'b1010 |
