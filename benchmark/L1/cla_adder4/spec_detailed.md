## 功能
4 位二进制加法器，除和与进位外，还输出用于多级级联的**组传播**（group propagate）与**组生成**（group generate）信号。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| a | input | 4 | 加数 A（无符号） |
| b | input | 4 | 加数 B（无符号） |
| cin | input | 1 | 进位输入 |
| sum | output | 4 | 和的低 4 位 |
| cout | output | 1 | 进位输出，即和的第 4 位 |
| p_out | output | 1 | 组传播：当且仅当每一位都满足 a[i] ≠ b[i] 时为 1 |
| g_out | output | 1 | 组生成：等于 cin = 0 时本模块的进位输出 |

## 行为
1. `{cout, sum} = a + b + cin`（5 位结果）。
2. `p_out = 1` 表示该 4 位块在 cin = 1 时必然产生进位输出、cin = 0 时必然不产生进位输出；等价于 a[3:0] ^ b[3:0] 的各位全为 1。
3. `g_out` 与 cin 无关，等于在 cin = 0 条件下计算 a + b 得到的进位输出。
4. 纯组合逻辑，无时钟与复位。

## 示例
| a | b | cin | sum | cout | p_out | g_out |
|---|---|---|---|---|---|---|
| 4'b1010 | 4'b0101 | 0 | 4'b1111 | 0 | 1 | 0 |
| 4'b1010 | 4'b0101 | 1 | 4'b0000 | 1 | 1 | 0 |
| 4'b1100 | 4'b0100 | 0 | 4'b0000 | 1 | 0 | 1 |
| 4'b0011 | 4'b0001 | 1 | 4'b0101 | 0 | 0 | 0 |
