## 功能
把 4 位十六进制数译成 7 段数码管段码。数码管为**共阳极**，段信号低电平点亮（0 = 亮，1 = 灭）。

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| hex | input | 4 | 待显示的十六进制数 0～F |
| seg | output | 7 | 段码，`seg[0]=a, seg[1]=b, seg[2]=c, seg[3]=d, seg[4]=e, seg[5]=f, seg[6]=g` |

## 段位布置
```
  aaa
 f   b
 f   b
  ggg
 e   c
 e   c
  ddd
```

## 真值表（seg[6:0] = gfedcba，低有效）
| hex | 显示 | seg[6:0] |
|---|---|---|
| 0 | 0 | 100_0000 |
| 1 | 1 | 111_1001 |
| 2 | 2 | 010_0100 |
| 3 | 3 | 011_0000 |
| 4 | 4 | 001_1001 |
| 5 | 5 | 001_0010 |
| 6 | 6 | 000_0010 |
| 7 | 7 | 111_1000 |
| 8 | 8 | 000_0000 |
| 9 | 9 | 001_0000 |
| A | A | 000_1000 |
| B | b | 000_0011 |
| C | C | 100_0110 |
| D | d | 010_0001 |
| E | E | 000_0110 |
| F | F | 000_1110 |

纯组合逻辑，无时钟与复位。
