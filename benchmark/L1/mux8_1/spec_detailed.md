## 功能
8 选 1 多路选择器，每路数据位宽为参数 `WIDTH`，带输出使能。

## 参数
| 参数 | 默认值 | 说明 |
|---|---|---|
| WIDTH | 4 | 每一路数据的位宽 |

## 端口
| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| din | input | 8×WIDTH | 8 路输入数据拼接：第 k 路占据 din[k×WIDTH+WIDTH−1 : k×WIDTH]，k = 0～7 |
| sel | input | 3 | 通道选择，0～7 |
| en | input | 1 | 输出使能 |
| dout | output | WIDTH | 输出数据 |

## 行为
1. `en = 1` 时，`dout` 等于第 `sel` 路输入，即 din 中从第 sel×WIDTH 位开始的 WIDTH 位。
2. `en = 0` 时，`dout` 为全 0，与 sel、din 无关。
3. 纯组合逻辑，无时钟与复位；sel 的 8 个取值都必须给出确定输出。

## 示例（WIDTH = 4）
| din | sel | en | dout |
|---|---|---|---|
| 32'h7654_3210 | 0 | 1 | 4'h0 |
| 32'h7654_3210 | 5 | 1 | 4'h5 |
| 32'h7654_3210 | 7 | 1 | 4'h7 |
| 32'h7654_3210 | 3 | 0 | 4'h0 |
